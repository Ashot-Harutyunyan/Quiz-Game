# Elegant Quiz App

A minimalistic and elegant quiz application built with React + Vite.

Live Demo:&nbsp;&nbsp;https://quiz-game-snowy-three.vercel.app/

---

## Features

- Random questions generation
- Timer countdown
- Correct / incorrect answer states
- Result statistics
- Responsive design
- Elegant dark UI
- Smooth animations
- React Hooks
- useReducer state management

---

## Technologies

- React
- Vite
- SCSS
- JavaScript (ES6)
